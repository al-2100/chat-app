# Chat App en Tiempo Real con GraphQL

Una aplicación de chat en tiempo real construida con React, TypeScript, Apollo Client y GraphQL. Permite a los usuarios enviar y recibir mensajes instantáneamente utilizando suscripciones GraphQL.

## Tecnologías utilizadas

### Frontend
- React 19
- TypeScript
- Apollo Client
- Tailwind CSS
- Shadcn/ui

### Backend
- Node.js
- Express
- Apollo Server
- GraphQL
- WebSockets para suscripciones en tiempo real

## Instalación y Ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/al-2100/chat-app.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd chat-app
   ```
3. Inicia el servidor
   ```bash
   cd chat-api
   npm install
   node server.js
   ```
4. Inicia el cliente
   ```
   cd chat-client
   npm install
   npm run dev
   ```

5. Abre tu navegador y ve a `http://localhost:5173` para ver la aplicación en funcionamiento.
